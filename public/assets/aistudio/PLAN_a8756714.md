# Implementation Plan — Agent Memory Hub

## Phase 1: Single-Container Scaffolding & Core Storage
- **Deliverables:** `Dockerfile` (multi-stage Node 20 UI build -> Python 3.12 slim runtime), `docker-compose.yml`, `.env.example`, `backend/requirements.txt`, `backend/app/config.py`, `backend/app/database.py`.
- **Verification:** Container builds cleanly; `/data/memory.db` initializes automatically in WAL mode with `sqlite-vec` loaded; `/health` returns `200 OK`.

## Phase 2: Cognitive Engine, Lazy Embeddings & Async Worker
- **Deliverables:** `backend/app/embeddings.py` (Zero-RAM lazy loader + `gc.collect()`), `backend/app/llm_service.py` (Smart Merge, Entity-Relation triple extractor, Context Distiller), `backend/app/engine.py` (Hybrid ranking, bi-temporal versioning/rollback, regex secret scrubber), `backend/app/worker.py` (`asyncio.Queue`, TTL expiration cleaner, dimension re-indexer).
- **Verification:** Switching `EMBEDDING_MODE` from `local` to `external` releases model memory; duplicate memories (`cosine > 0.85`) merge cleanly without creating duplicate rows.

## Phase 3: Dual MCP Server & Dashboard REST API
- **Deliverables:** `backend/app/mcp_server.py` (Tools: `recall_memory`, `store_memory`, `learn_from_mistake`, `supersede_memory`; Resources: `core-directives`, `session-summary`), `backend/app/api_routes.py` (CRUD, Temporal Rollback, Graph JSON, Playground Debugger, Toggleable `/ingest`, Import/Export/Bulk Seed, Settings/Reindex), `backend/app/main.py` (Dual-Auth middleware + SPA static router).
- **Verification:** Both `/mcp` (Streamable HTTP) and `/sse` (Legacy SSE) authenticate via Bearer token; `/api/v1/*` and `/` enforce Basic Auth; `/api/v1/ingest` returns `403` when disabled and `202` when enabled.

## Phase 4: Raycast/Linear React Dashboard UI
- **Deliverables:** `frontend/` Vite + React + TypeScript + Tailwind app with `en.json` / `id.json` i18n, Dark/Light theme tokens, `Cmd/Ctrl + K` Command Palette, and all 5 views (`OverviewTab`, `ExplorerTab`, `GraphTab`, `PlaygroundTab`, `SettingsTab`).
- **Verification:** `npm run build` succeeds with zero TypeScript errors; compiled `dist/` serves cleanly from FastAPI.

## Phase 5: End-to-End Integration Check
- **Deliverables:** Final verification of multi-workspace isolation (`hermes` + `global`), dimension change + live re-indexing, and JSON export/import round-trip.
