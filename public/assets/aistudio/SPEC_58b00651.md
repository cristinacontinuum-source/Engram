# Technical Specification — Agent Memory Hub

## 1. Embedded SQLite + `sqlite-vec` Database Schema (`/data/memory.db`)
Enable `PRAGMA journal_mode=WAL;`, `PRAGMA synchronous=NORMAL;`, and `PRAGMA foreign_keys=ON;` on startup.

```sql
-- 1. Core Memories Table (Semantic, Procedural, Episodic + Bi-Temporal + TTL)
CREATE TABLE IF NOT EXISTS memories (
    id TEXT PRIMARY KEY,
    workspace TEXT NOT NULL DEFAULT 'global',
    content TEXT NOT NULL,
    memory_type TEXT NOT NULL CHECK(memory_type IN ('semantic', 'procedural', 'episodic')),
    source TEXT NOT NULL DEFAULT 'agent_inferred' CHECK(source IN ('user_explicit', 'agent_inferred', 'tool_error', 'seed_import')),
    confidence REAL NOT NULL DEFAULT 0.85,
    is_pinned INTEGER NOT NULL DEFAULT 0,
    status TEXT NOT NULL DEFAULT 'active' CHECK(status IN ('active', 'superseded')),
    superseded_by TEXT REFERENCES memories(id) ON DELETE SET NULL,
    access_count INTEGER NOT NULL DEFAULT 0,
    last_accessed_at TEXT NOT NULL,
    valid_from TEXT NOT NULL,
    valid_to TEXT,
    expires_at TEXT, -- Nullable ISO timestamp for temporary TTL memories
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_memories_ws_status ON memories(workspace, status);
CREATE INDEX IF NOT EXISTS idx_memories_type ON memories(memory_type);
CREATE INDEX IF NOT EXISTS idx_memories_expires ON memories(expires_at);

-- 2. Dynamic Vector Table (Recreated automatically on dimension change + re-index)
-- Example for 1536 dims (or 384 dims for multilingual-e5-small):
CREATE VIRTUAL TABLE IF NOT EXISTS vec_memories USING vec0(
    memory_id TEXT PRIMARY KEY,
    embedding float[1536] distance_metric=cosine
);

-- 3. Lightweight Knowledge Graph (Entities & Edges)
CREATE TABLE IF NOT EXISTS entities (
    id TEXT PRIMARY KEY,
    workspace TEXT NOT NULL DEFAULT 'global',
    name TEXT NOT NULL,
    entity_type TEXT NOT NULL DEFAULT 'concept',
    UNIQUE(workspace, name)
);

CREATE TABLE IF NOT EXISTS edges (
    id TEXT PRIMARY KEY,
    workspace TEXT NOT NULL DEFAULT 'global',
    source_id TEXT NOT NULL REFERENCES entities(id) ON DELETE CASCADE,
    relation TEXT NOT NULL,
    target_id TEXT NOT NULL REFERENCES entities(id) ON DELETE CASCADE,
    memory_id TEXT REFERENCES memories(id) ON DELETE CASCADE,
    created_at TEXT NOT NULL
);

-- 4. Runtime Configuration (Persisted overrides from Dashboard Settings)
CREATE TABLE IF NOT EXISTS settings (
    key TEXT PRIMARY KEY,
    value TEXT NOT NULL,
    updated_at TEXT NOT NULL
);

-- 5. Retrieval & Token Savings Telemetry
CREATE TABLE IF NOT EXISTS telemetry_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    workspace TEXT NOT NULL,
    query TEXT NOT NULL,
    raw_tokens INTEGER NOT NULL,
    distilled_tokens INTEGER NOT NULL,
    latency_ms REAL NOT NULL,
    created_at TEXT NOT NULL
);
```

## 2. Composite Retrieval Ranking Formula
For active memories (`status = 'active' AND (expires_at IS NULL OR expires_at > now)`) within `workspace IN (:workspace, 'global')`:

$$\text{FinalScore} = (0.55 \times S_{\text{vector}}) + (0.20 \times S_{\text{graph}}) + (0.15 \times S_{\text{recency}}) + (0.10 \times \text{Confidence}) + B_{\text{pinned}}$$

- **$S_{\text{vector}}$**: `1 - cosine_distance` (`[0, 1]`).
- **$S_{\text{graph}}$**: `1.0` if linked via 1-hop entity match from query entities, `0.0` otherwise.
- **$S_{\text{recency}}$**: Exponential time-decay $e^{-\lambda \cdot \Delta t_{\text{days}}}$ ($\lambda = 0.03$), overridden to `1.0` if `is_pinned = 1`.
- **$B_{\text{pinned}}$**: `+0.15` boost if `is_pinned = 1` or `memory_type = 'procedural'`.

## 3. MCP Server Contract (`/mcp` & `/sse`)

### Tools
1. **`recall_memory(query: str, workspace: str = "global", top_k: int = 5, distill: bool = True) -> dict`**
   - Executes hybrid retrieval (`workspace` + `"global"`), increments `access_count`, and if `distill=True`, compresses results via Fast LLM. Logs telemetry (`raw_tokens` vs `distilled_tokens`).
2. **`store_memory(content: str, memory_type: str = "semantic", workspace: str = "global", source: str = "agent_inferred", confidence: float = 0.85, ttl_hours: Optional[int] = None) -> dict`**
   - Runs regex secret scrubber, enqueues to `asyncio.Queue` for async deduplication (`cosine > 0.85` -> LLM smart merge), graph triple extraction, and embedding. Returns `{"status": "queued", "job_id": ...}` immediately.
3. **`learn_from_mistake(context: str, mistake_or_error: str, rule_learned: str, workspace: str = "global") -> dict`**
   - Stores a high-priority `procedural` rule (`source="tool_error"`, `confidence=0.95`) so future similar tasks surface the anti-pattern automatically.
4. **`supersede_memory(old_memory_id: str, new_content: str, reason: str, workspace: str = "global") -> dict`**
   - Marks `old_memory_id` as `status='superseded'`, `valid_to=now()`, inserts the updated memory, and sets `superseded_by`.

### Resources
1. **`memory://core-directives/{workspace}`**: Returns all `is_pinned = 1` memories and top `procedural` rules for `{workspace}` + `"global"`.
2. **`memory://session-summary/{workspace}`**: Returns a synthesized bullet summary of the 15 most recent active memories.

## 4. Dashboard & Ingest REST API (`/api/v1`)
- `GET /api/v1/stats` — KPI metrics (active memories, workspaces, tokens saved %, avg latency ms, queue depth, active RAM MB).
- `GET /api/v1/memories` — Paginated list with filters (`workspace`, `type`, `status`, `search`).
- `POST /api/v1/memories` — Manual memory creation (`source='user_explicit'`, `confidence=1.0`).
- `PATCH /api/v1/memories/{id}` — Edit content, toggle `is_pinned`, or update workspace.
- `DELETE /api/v1/memories/{id}` — Hard delete memory and cascade vector/edge rows.
- `GET /api/v1/memories/{id}/history` — Returns temporal chain (`superseded` -> `active` versions).
- `POST /api/v1/memories/{id}/rollback` — Restores a `superseded` version to `active` and supersedes the faulty newer version.
- `GET /api/v1/graph?workspace=global` — Returns `{ nodes: [...], edges: [...] }` for canvas visualization.
- `POST /api/v1/playground/query` — Runs retrieval + distillation in debug mode, returning full score breakdowns (`vector`, `graph`, `recency`, `final`) and raw vs. distilled token counts.
- `POST /api/v1/ingest` — **Toggleable Webhook** (`403` if `enable_ingest_webhook == false`). Accepts `{ "workspace": "hermes", "messages": [...] }`, extracts discrete facts and rules via Fast LLM in the background worker.
- `GET /api/v1/export?workspace=all` — Downloads portable JSON snapshot of memories + graph edges.
- `POST /api/v1/import` — Imports JSON backup or **Bulk Seed Rules** (`{ "mode": "json" | "bulk_seed", "workspace": "global", "pin_all": true, "payload": ... }`) and queues embedding generation.
- `GET /api/v1/settings` & `PUT /api/v1/settings` — Reads/updates LLM config, Embedding mode (`external` vs `local`), and `enable_ingest_webhook` toggle.
- `POST /api/v1/settings/test-embedding` — Tests connection, measures latency, and returns detected vector dimension.
- `POST /api/v1/settings/reindex` — Recreates `vec_memories` with the current model's dimension and re-embeds all active memories asynchronously with progress tracking (`GET /api/v1/settings/reindex/status`).
